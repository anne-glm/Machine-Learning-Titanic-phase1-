# Titanic Survival Prediction

A machine learning project based on the Kaggle Titanic dataset.

## Models

- Logistic Regression
- Decision Tree
- Random Forest

## Preprocessing

- Filling missing values in `Age`
- Filling missing values in `Embarked`
- Encoding `Sex`
- One-hot encoding of categorical features
- Processing `Fare`

## Results

- Validation accuracy: 81%
- Kaggle score: 0.75119
